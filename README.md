# PiggyCrash / dgashandy Portfolio Website

A premium, interactive 3D holographic portfolio website featuring a futuristic cybernetic HUD (Heads-Up Display) design. Built using modern frontend technologies and 3D web graphics, this site showcases the developer's work, experience, and projects in an immersive, high-fidelity environment.

---

## 🌟 Features

*   **Interactive 3D Holograms**: Immersive 3D wireframe Earth with custom particle systems, glow effects, and interactive OrbitControls, alongside interactive 3D laptop and keyboard models using **Three.js**.
*   **Cybernetic HUD Interface**: Valorant/holographic-inspired aesthetic featuring clean dark themes, neon accents, and cyber-grid layout styles.
*   **Dynamic Projects Showcase**: Automatically fetches and renders projects from a structured `portfolio.json` file.
*   **Smooth Micro-Animations**: Engaging hover states, custom custom-cursor ring follower, typewriter terminal effects, and entry/exit section transitions.
*   **EmailJS Contact Form**: Direct message delivery from the UI to email without needing a custom backend server.
*   **Fully Responsive**: Adaptive layouts for mobile devices, tablets, and widescreen desktop monitors.

---

## 🛠️ Technology Stack

*   **HTML5 & CSS3**: Semantic structuring and custom styling using CSS variables, grid, flexbox, and keyframe animations.
*   **JavaScript (ES6)**: Clean DOM manipulation, asynchronous fetching, and state management.
*   **Three.js**: WebGL-based library for rendering the complex 3D wireframes, particles, and geometries.
*   **Feather Icons**: Crisp, vector icons for UI actions and navigation.
*   **EmailJS**: Client-side email dispatch integration.
